Treasury & Financial Analysis Dashboard

Overview

An Excel-based simulated treasury and financial analysis dashboard designed to monitor cash inflows, outflows, monthly cash flow, budgets, pending transactions, and account-level activity.

The project uses simulated financial data and demonstrates practical Excel skills relevant to financial analysis and treasury operations.

Key Features

- Automated calculation of total inflows and outflows
- Net cash-flow analysis
- Monthly inflow vs. outflow analysis
- Monthly net cash-flow tracking
- Budget vs. actual expenditure analysis
- Variance calculations by spending category
- Pending transaction monitoring
- Account-level inflow and outflow analysis
- Excel charts for financial visualization
- Formula-driven dashboard reporting
